# Seasonal Agriculture Performance Analysis

## Project
VOIS AICTE Batch 1 2026–2027 Major Project

## What is included
- `Seasonal_Agriculture_Performance_Analysis.ipynb` — complete analysis workflow
- `seasonal_agriculture_performance_dataset.csv` — original dataset
- `requirements.txt` — Python packages
- `outputs/` — generated summaries after running the notebook

## Run
```bash
pip install -r requirements.txt
jupyter notebook Seasonal_Agriculture_Performance_Analysis.ipynb
```

## Main analysis
- data validation and missing-value handling
- seasonal performance comparison
- crop × season profitability
- irrigation and water-efficiency analysis
- correlation and relationship screening
- Kruskal–Wallis significance test
- outlier awareness
- Seasonal Opportunity Score for crop-season ranking

## Core conclusion
Kharif is the strongest aggregate season in the supplied data. Zaid has negative aggregate profit and the weakest water efficiency, so the most useful planning approach is selective crop-season choice rather than treating all seasons equally.
